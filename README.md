# 👨‍💻 من أنا

أنا مطور برمجيات وخريج علوم حاسوب، أركز على تطوير الأنظمة الخلفية (Back-End) وبناء واجهات برمجية (APIs) وأنظمة الذكاء الاصطناعي والأتمتة.

أهتم ببناء مشاريع عملية تعتمد على مبادئ هندسة البرمجيات، وأسعى إلى كتابة كود نظيف، وإنشاء أنظمة مرنة وقابلة للتوسع، مع التعلم المستمر ومواكبة أحدث التقنيات.
